Restart and Stop

Start has no confirmation. Restart says what stops, what stays and what it brings. Stop has the only red button in the UI and says it lasts across host reboots. Deleting isn't in the UI.

Loading and empty

Skeleton rows only on the very first load; after that rows update in place. Someone without a workspace learns what one is and who makes it.

Sign in to app

The address an admin can send a newcomer. Its GET is this page and signs in nothing; the button posts, and the browser goes straight to the app with a one-time link it never shows. Then the errors.

Console

The serial console, shared: one connection per VM on the host, fanned out to everyone watching, with the last output kept for whoever opens it next. Here alice restarted with the console open to pick the previous NixOS generation.

Host

Admins only. The host page is a section per node: its state, Close or Reopen, its memory as one bar, with what each pool holds and waits for, the reserve and what's free, its disk, and its workspaces, each made at run time with Move…. A node that doesn't answer keeps its workspaces listed, Unreachable. Move lists the open nodes of the same build but the workspace's own.
